### Бот для игры в Google T-Rex

(Проверен на https://chromedino.com)



\-----------------------------------------------------------------------------------------------------



Инструкция:



1. Запустить код (очевидно)
2. В появившемся окне кликнуть ЛКМ на динозавра (он должен выделиться зелёной рамкой)
3. Если появилось второе окно - можно запускать игру
4. Для выхода нажать ESC



\-----------------------------------------------------------------------------------------------------



Простое объяснение как работает:



1. При запуске выводится окно с вашим уменьшенным экраном
2. При клике ЛКМ находятся все соседние тёмные пиксели внутри динозавра (поиск размеров динозавра)
3. Формируется игровое поле в зависимости от динозавра
4. Выводится игровое поле со всеми нужными зонами определения:

&#x09;- Красная зона - основная зона прыжка

&#x09;- Жёлтая зона - аварийная зона прыжка (на случай если основная зона не сработала)

&#x09;- Синяя зона - начало отсчёта таймера для замера скорости

&#x09;- Зелёная зона - остановка отсчёта таймера для замера скорости

5\. Считывая зоны, программа имитирует нажатие стрелки вверх

6\. При нажатии ESC программа останавливается
